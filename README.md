# okilin-web

Public static pages for the **OKILIN** app — Privacy Policy, Terms & Conditions,
and the email-confirmation page. Served via GitHub Pages.

- `privacidade.html` — Política de Privacidade
- `termos.html` — Termos e Condições
- `confirmado.html` — página de confirmação de email
- `index.html` — landing

## GitHub Pages
Settings → Pages → Source: `main` / root. Public URLs, e.g.:
`https://badjaja.github.io/okilin-web/privacidade.html`
